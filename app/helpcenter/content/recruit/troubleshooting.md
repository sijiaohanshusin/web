## 按步骤操作

1. 先确认右上角显示的等级：新注册应为“招新成员”。
2. 招新成员可查看公开公告、维护本人资料和报名，不可进入会员资料、活动报名、项目内部功能或论坛账号体系。
3. 一面通过后成为预备会员，会员内容和论坛 SSO 才会开放。
4. 遇到 403 通常是权限不足；遇到 404 先核对网址，避免使用旧收藏链接。
5. 页面提交失败时记录网址、操作步骤和错误提示，联系站务时不要发送密码、验证码或完整身份证明截图。

## 你应该看到

你能区分正常权限限制与网站故障，并提供足够的信息帮助站务定位问题。

## 常见问题速查

| 现象 | 处理方法 |
|---|---|
| 验证码 60 秒内不能重发 | 等待倒计时结束；使用最新验证码 |
| 验证码连续错误 | 最多 5 次后作废，重新获取 |
| 学号、邮箱或手机号已存在 | 使用原账号登录或找回密码 |
| 报名提交后不能修改 | 在 QQ 群联系站务更正 |
| 论坛无法登录 | 一面通过前属于正常权限限制 |
| 手机页面拥挤 | 竖屏使用并刷新；不要开启强制桌面模式 |
| 状态与通知不一致 | 以招新页状态为主，并联系站务复核 |
