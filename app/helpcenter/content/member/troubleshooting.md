## 常见问题速查

| 问题 | 首选处理 |
|---|---|
| 老会员注册后不能登录 | 等待管理员审核，不要反复改密 |
| 审核邮件未收到 | 查垃圾箱，并提供用户名请站务查询 |
| 验证码收不到 | 确认邮箱、等待 60 秒、检查每日额度 |
| 资料重复 | 停止注册，找回原账号或联系站务 |
| 会员资源无权限 | 核对等级和条目可见范围 |
| 论坛显示游客 | 官网重新登录后从官网进入论坛 |
| 图片上传失败 | 检查格式、5 MB、8 MP 和 20 张上限 |
| 展示没有更新 | 保存草稿后需要再次发布 |
| 展示被下架 | 查看原因，修改草稿并联系管理员解除限制 |

## 求助时提供

1. 发生时间和页面网址。
2. 账号用户名及当前显示的会员等级。
3. 从进入页面开始的完整操作步骤。
4. 页面错误文字或已遮挡隐私的截图。
5. 浏览器和设备类型。

## 不要提供

密码、邮箱验证码、Cookie、会话链接、身份证件原图或与问题无关的私密资料。
