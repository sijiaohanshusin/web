# 美术资产清单与提示词

给「你去生成 / 去拍，我来接进站里」这件事用的工单。风格已经定型（见
`docs/排版与质感增强计划.md`）：黑底、信号青、焊锡铜、得意黑标题、走线数字、
宋体导语、器械丝印记号。下面每一项都写了**用在哪、什么规格、怎么验收**。

## 先分清三类，别混着做

| 类别 | 谁做 | 为什么 |
| --- | --- | --- |
| **① 协会现场照** | **必须真拍** | 站上所有「缺图」的位置，语义都是「缺我们**自己**的照片」。放 AI 生成的假照片，等于让新生看着假成员、假实验室做决定 —— 这条是项目底线（`core/slots.py` 的设计说明）。 |
| **② 材质与氛围** | **生图 AI 合适** | 玻纤基板微距、焊点反光、抽象暗场 —— 不需要电气正确性，不含人，也不承担信息。这是 AI 性价比最高的一类。 |
| **③ 技术图** | **我做，别用 AI** | 原理图、引脚图、波形、频响曲线、元件符号。AI 会画出电气上讲不通的东西，而这是电子科技协会的站，学生会当真读。这类是规则驱动的，我用 KiCad / matplotlib / SVG 生成器做，还能写校验脚本。 |

## ② 生图 AI：材质与氛围

### 通用硬规格（所有生成图都要满足）

- **色彩**：以近黑为主（#050506 ~ #0b0b0e）。高光只允许**信号青**
  #0da9cd / #41d8e8 与**焊锡铜** #c98a3d / #e2ab63。
  **不要**紫红/洋红/霓虹赛博朋克那套配色 —— 会和全站冲突。
- **不能有任何文字**。AI 写的字都是乱码，而且假型号在电子协会的站上会被当真读。
- **不能有可辨识的电路或原理图**（走线、焊盘、元件轮廓可以，但不要出现"看起来像
  能工作的电路"的结构）。
- **不要人、不要手、不要人脸。** 涉及人的一律真拍（隐私同意口径）。
- **不要水印、边框、圆角、投影、暗角**（vignette）。这些我在 CSS 里做，图上带了会打架。
- **交付格式**：PNG，不要 JPEG（暗部会有块）。纹理类 2048×2048，横幅
  2560×1080，社交卡 1200×630。我负责转 webp/avif 与压缩。
- **命名**：`tex-<名字>.png` / `banner-<章节>.png`，全小写连字符。

### 验收标准（我拿到后会这么查）

1. 铺到 #050506 上不出现色带（banding）—— 暗部渐变最容易出这个问题。
2. 缩到 1/4 尺寸不出摩尔纹（细密走线纹最容易出）。
3. 纹理类要**四方连续**（我会把它拼 2×2 看接缝）。
4. 无文字、无人、无假电路。
5. 主色相在青/铜两支上，不跑到紫或橙红。

### T1 玻纤基板微距（最需要，用在区块底纹）

> **中文**：极暗的电路板基板微距特写，能看见 FR4 玻璃纤维布的交织纹理，
> 表面覆一层哑光深绿阻焊漆，几乎全黑，只有极弱的青色环境光从侧面斜照。
> 无元件、无走线、无文字。平铺可四方连续，正交视角，画面平整无透视。
>
> **English**: extreme macro of a bare FR4 circuit board substrate, woven glass
> fibre weave visible through matte dark green solder mask, almost black,
> very faint cyan rim light from the side, no components, no traces, no text,
> orthographic top-down, seamless tileable texture, flat even lighting
>
> **负面**：text, letters, numbers, logo, components, chips, wires, people,
> hands, vignette, watermark, purple, magenta, neon, glossy reflection

用途：`.surf-weave` 现在是 CSS 斜纹，换成真实材质会明显厚一档。

## ③ 我来做的技术图（不要用 AI）

按性价比排，做完会像现有的走线数字一样进 `app/static/brand/` 并配校验脚本：

1. **元件符号集**（电阻/电容/电感/二极管/三极管/运放/MCU/晶振/接插件/GND）——
   和现有 19 个线性图标同风格（1.7 描边、24 viewBox），既能喂新生指南也能当装饰。
2. **波形与曲线**（方波上升沿、RC 充放电、运放频响、频谱）—— matplotlib 或手写
   SVG 生成，数据是真的，坐标轴用站上的 mono 字体。
3. **引脚定义图**（常用开发板）—— 纯几何 + 文字，KiCad 或 SVG 生成。
4. **原理图片段**（分压、跟随器、去耦、稳压）—— 用符号集拼，**电气必须讲得通**。
5. **走线拉丁字母**（如果需要 `SINCE`、`REV.A` 这类也用自制字）—— 数字那套的扩展。

需要你提供的只有内容清单：**指南里哪些地方现在讲不清、缺一张图**。你给章节和
段落，我来画。

### 尺寸与安全区是算出来的，不是随手定的

**每张 2560×860（≈2.98:1），PNG。**

页头在桌面是 1440×274（5.26:1）、窄屏是 390×229（1.70:1） —— 同一张图要塞进
差三倍的两个画框，靠 `cover` + 右对齐裁：

- 桌面看到的是**竖向 22%~78%**（整个宽度都在）
- 窄屏看到的是**横向 43%~100%**（整个高度都在）

所以：

- **意象必须落在「右 40%（横向 60%~100%）× 竖向中间 56%（22%~78%）」这块交集里。**
  出了这块，某一个屏幕尺寸下就看不见。
