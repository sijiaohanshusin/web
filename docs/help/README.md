# 任务式帮助中心

新版主要入口是网页帮助中心，不再要求成员先下载并通读整本手册。
目前处于候选验收阶段，未部署到正式站。

## 三类读者

| 读者 | 入口 | 阅读方式 |
| --- | --- | --- |
| 招新成员 | `/help/recruit/` | 注册、报名、查进度，短步骤与检查点 |
| 老会员 | `/help/member/` | 恢复身份、使用资源、设计和发布展示 |
| 站务及系统管理员 | `/help/admin/` | 前置条件、权限边界、风险与结果核对 |

`/help/search/?q=` 提供按任务搜索。管理文章在服务端按权限过滤，不能靠隐藏按钮代替鉴权。
管理截图使用同一权限的受保护接口，不放入公共静态目录。仓库为公开项目，所有源稿和截图必须先脱敏；网页访问限制不等于源代码保密。

## 唯一内容源

- `app/helpcenter/content/<audience>/*.md`：JSON front matter 与 Markdown 正文。
- `app/helpcenter/assets/`：脱敏截图，文件名与每篇 `screenshots` 字段对应。
- 元数据包含权限、路由、检查点、截图编号、核验日期和适用版本。
- `docs/manuals/` 保留旧版档案，只作为历史参考。不要双份维护正文。

修改页面后先更新对应任务及截图，再运行 `python manage.py test helpcenter`（在 `app/` 目录）。
浏览器验收使用 `scripts/check_experience.py`，只允许本地 DEBUG + SQLite；禁止对生产站运行写入测试。

## 首次引导与离线手册

根据 2026-09-05 最新确认，PDF 改为首次上手指南，不再把全部网页章节逐篇复制成三本大部头。网页保留任务搜索、详细步骤与故障排查；PDF 只带读者完成第一次实际操作。

三个顺序由 `app/helpcenter/onboarding.json` 统一记录，引用 Markdown 文章而不复制正文。网页每册顶部的“第一次使用”可以键盘展开；管理路线仍在服务端过滤系统专属章节。

| 读者 | 首次上手路线 | 后续 PDF 重点 |
| --- | --- | --- |
| 招新成员 | 准备与注册 → 完善资料 → 提交报名 → 查进度与通知 → 权限和退出 | 分步注册与手机报名，强调注册不等于已报名 |
| 老会员 | 身份恢复与登录 → 完善资料 → 资料活动 → 论坛交流 → 自愿公开卡片 | 等待审核、私有档案与公开展示分离、首次论坛发帖 |
| 管理人员 | 权限与驾驶舱 → 成员审核 → 第一篇公告 → 活动反馈 → 结果核对与交接 | 先保存未发布版本再预览、发布和撤回，操作对象与权限核对 |

PDF 目标是每册约 8–12 页的短流程，采用大幅局部截图、编号操作与完成检查，复杂配置用网页链接延伸。此页数只是设计预算，不以压小截图强行达标。普通会员的论坛发帖与管理人员的主站公告是两种操作，不混用入口或权限。

论坛首次使用链已在隔离 NodeBB 4.14.0 中验证：实际主站登录、论坛 SSO、首篇主题、回复、进入队列、论坛管理员接受、回到主题确认，以及手机编辑器操作。公共邮箱验证了不同身份的访问、真实归档去重、只读写入拒绝和安全排版。新截图均为虚构账号、帖子和合成邮件，不包含正式邮箱内容；不能把合成邮件测试写成真实 Gmail IMAP 网络投递已验收。

`scripts/check_forum.py` 随 CI 使用一次性 PostgreSQL 与真实论坛。`scripts/manuals/prepare_forum_images.py` 只对通过的证据作无损局部裁切，避免把整个桌面缩成小图；没有通过完整结果检查不得生成最终手册截图。成员册分别说明桌面“提交”和手机向右箭头入口，管理册区分主站入会审核与论坛帖子审核。

目前只完成首次路线、部分新截图和管理/会员主站浏览器验证，尚未生成新版精简 PDF 定稿。下述旧全文导出保留为资料参考，不继续作为主要交付版本。

### 旧全文参考导出

使用工作区文档运行时执行 `scripts/manuals/build_help.py`，从同一内容源生成三册 DOCX。
`scripts/manuals/render_help_word.py` 在 Windows 上以 Word 为转换后端，调用文档技能的 `render_docx.py` 渲染。
产物位于本地 `docs/help/dist/`，逐页验收材料位于 `.shots/documents/`，均不自动部署。

当前旧全文副本不能作为首次引导定稿发放。新版最终 PDF 必须来自通过逐页视觉验收的同一份 DOCX。

离线目录现在使用本册书签与页码，不再依赖联网才能跳转；每个任务末尾可返回目录。截图由 `scripts/manuals/capture_registration.py` 补充当前用户名字段的桌面与手机局部，不提交注册、不发送邮件。

最新同源重渲染：招新册 32 页、老会员册 35 页、管理册 38 页。已修复桌面局部图误当手机图缩小、源稿图注在导出时丢失、返回目录单独占页的问题；Word 页码字段会在打开时更新。

运行 `scripts/manuals/check_help_exports.py` 检查内部书签、替代文字、作者元数据、PDF 是否过期及返回目录孤页，并输出截图裁切复核队列。该脚本的像素密度估算仅用于提醒，不能判断图片中文字是否真正可读，更不能代替逐页视觉检查。当前三册共有 90 个内部链接，结构检查通过；旧整页截图仍有 19/22/26 项需人工放大复核（招新/老会员/管理）。

三册仍不能作为定稿发放。最新管理册第 27–29 页已针对勋章图文改进复核，其余页需按最新渲染重新检查；不能沿用旧页数或旧截图的验收结论。每次核验的证据范围见 `docs/audit/2026-09-05-experience.md`。

## 发布门槛

1. 各角色能执行的操作与文章权限一致，目录和搜索不泄漏不可见标题。
2. 所有截图可解码、可放大，手机号、邮箱、验证码和真实身份已遮挡。
3. 卡片单独公开、可选个人页及用户名新规则的截图更新完成。
4. 多设备、键盘、缓存、完整回归与 PostgreSQL CI 通过。
5. 备份与部署验证通过后才把版本标记从候选改为正式。
