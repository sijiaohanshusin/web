# 论坛分级交流

2026-10-03 起的权限方案。新会员注册并验证邮箱即可使用官网身份参与论坛公共交流，无需通过面试。主站资料、活动、项目及公共邮箱的权限独立保留。

| 等级 | 公共板块 | 研习交流 | 内部事务 | 站务协作 |
|---|---|---|---|---|
| 游客 | 浏览 | 无 | 无 | 无 |
| 招新成员（1） | 发帖、回复 | 无 | 无 | 无 |
| 预备会员（2） | 发帖、回复 | 发帖、回复 | 无 | 无 |
| 科协会员（3） | 发帖、回复 | 发帖、回复 | 发帖、回复 | 无 |
| 站务管理（4）、系统管理员（5） | 发帖、回复 | 发帖、回复 | 发帖、回复 | 发帖、回复 |

可见范围由原生 NodeBB 板块 ACL 控制；发帖时选择带等级标注的板块即可。三个内部板块只授予上表等级组读写权限，清除默认注册用户、联邦用户、职位、旧组和逐用户授权。原生论坛管理员可管理全部板块，主站等级不自动授予论坛管理员。

基础交流保留防垃圾发帖审核；审核不以面试或会员升级为条件。等级组禁止自行加入及申请加入，由主站 SSO 同步。等级变化在浏览器取得主站新 Cookie 后，下一次论坛整页请求同步；现有会话共享机制不提供跨设备即时撤销旧令牌的保证。

论坛上传文件当前只要求登录，不按帖子等级保护。需限制下载的文件应由官网资料站分级发布，并在帖子中引用对应资料链接。

## 发布

1. 先完成当前提交的 Django、浏览器及隔离 NodeBB/PostgreSQL 联调。
2. 将 `groups-v2.js`、`tiered-access.js`、兼容入口 `internal-board.js` 安装到论坛 `/opt/config` 挂载目录。
3. 在论坛容器执行 `node /opt/config/tiered-access.js` 预览，再执行 `node /opt/config/groups-v2.js` 与 `node /opt/config/tiered-access.js --apply --snapshot /opt/config/tier-acl-<时间>.json`。保留权限变更前记录，重启论坛清除进程缓存。已有“内部事务”保留 cid、帖子及回复；新板块先以禁用状态建立，撤销默认授权后才启用。
4. 使用 `ops/release.sh <完整提交号>` 发布主站，核对实际版本和就绪状态。先落实论坛 ACL，再开放新会员 SSO。
5. 运行 `launch-content.js --apply --snapshot <独立路径>` 更新协会自己发布的使用说明，保留主题链接及原回复。检查帮助页、公开列表和实际 ACL。

`deploy-forum.sh` 已使用同一权限脚本，重复执行不会创建重复板块；遇到同名歧义或原本非公开的公共板块立即停止。不要对公共邮箱运行此脚本的权限重置逻辑。回退主站使用发布流程保留的镜像与源码；需要回退论坛 ACL 时先禁用新板块，再依据权限快照恢复既有板块名称和授权，不删除帖子。

## 验证范围

`accounts.tests.SsoTests` 覆盖新会员 Cookie、未激活及待审核拒绝、升降级刷新、论坛入口与主站项目隔离。`scripts/check_forum.py` 使用隔离账号，验证游客和 1–5 级登录、私密分类/帖子/正文接口、拒绝越级写入、列表与搜索不泄露、升降级同步、新会员真实发帖与回复、会员选择私密板块发布及低等级直链拒绝。原公共邮箱只读及隐私检查继续执行。
