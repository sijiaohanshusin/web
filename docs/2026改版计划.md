## 设计语言：借方法，不借外观

从影视飓风借的是**叙事手法**：滚动即剪辑（区块钉住、分镜推进、节拍快慢交替）、巨型排版当画面主体、纯黑场做转场、数据可视化当叙事、真实素材与器材特写优先。

**明确不借**：荧光黄/橙品牌色、影视胶片调色、Vlog 手持感、综艺花字。那些是影视公司的身份符号，套在电子科技协会身上就是 cosplay。

## 三条不可妥协的约束

1. **首访可以慢**，但必须有真实进度反馈。preloader 是分镜 00 的正式组成，不是补丁。二次访问靠 nginx `immutable` 长缓存。
2. **移动端不降级**。按「能力」分支而非设备档次：支持 WebGL 就跑完整 3D 与完整分镜，手机只调 DPR 上限与几何密度。只有两种情况降级：`prefers-reduced-motion`（无障碍要求）与 WebGL 完全不可用（退回 SVG 描线）。
3. **无 Node 构建链**。第三方库以压缩产物直接提交进 `app/static/vendor/`，用 `scripts/vendor_sync.py` 同步。理由：服务器 2 核 1.6G 且在其上 `docker compose build`；国内公共 CDN 不可靠。

## 已踩过的坑（不要再踩）

| 坑 | 结论 |
| --- | --- |
| B 站接口 412 | `Referer` 是风控开关，`python-requests` 默认 UA 在黑名单。用自报身份 UA 且不发 Referer。`/x/series/recArchivesByKeywords` 比 `/view` 更容易限流，建议在驾驶舱填 `featured_video_bvids` 走按 BV 号取数 |
| 测试跑 267 秒 | 瓶颈是 PBKDF2 不是网络。测试期换 `MD5PasswordHasher`，降到 4 秒 |
| Django `{# #}` | **只支持单行**。跨行注释必须用 `{% comment %}`，否则注释里的 `{% static %}` 会被真的执行 |
| ES module 相对 import 不改写 | Django 的 `support_js_module_import_aggregation` 默认 `False`。已在 `config/storage.py` 子类化打开，否则 `three.module.min.js` 内部的 `./three.core.min.js` 在生产 404，而本地 DEBUG 看不出来 |
| `lenis.min.js` 让 collectstatic 崩 | 它带 `sourceMappingURL` 注释，ManifestStatic 要求 `.map` 也在静态目录。`vendor_sync.py` 统一剥除 |
| 独立 `.svg` 一片空白 | 走 XML 解析器，**任何属性都必须带值**。`data-esta-logo` 这种无值写法会让整图解析失败，`SVGLoader` 也读不出 |
| 焊盘变成实心圆点 | 走线不能画到焊盘圆心，必须止于环外缘（半径 14），否则填掉内孔 |
| `SiteConfig` 加字段 | 必须把缓存键 `core:site_config:v3` bump 版本号。生产是 DatabaseCache，缓存的是 pickle 实例，TTL 1 小时 |
| `build_fonts.py` 的中文子集 | 是**从模板文案里扫出来的**。重做文案后不重跑，新标题字会回退系统黑体 |

- [x] **9. 视频槽组件**
  实际结论：**视频槽是图片槽的超集，不是另一套东西。** `SlotSpec` 加一个 `kind`（`image` / `video`），`MediaSlot` 加 `video_mp4` / `video_webm`，而 `image` 字段身份变成「封面帧」。于是「片子还没剪好、只传了封面」是一个完整可用状态，`prefers-reduced-motion` 下显示的也是这一帧 —— **不需要为降级另备素材**。
  - `<video muted loop playsinline preload="metadata">` + poster，**刻意不写 `autoplay`**。播放交给 `app/static/js/video-slots.js` 按能力决定：`prefers-reduced-motion` 不播、省流（`navigator.connection.saveData`）不播且把 `preload` 压到 `none`、其余用 IntersectionObserver 进视口才播、离开就暂停。省流这条只影响「视频是否自动播」，**不降级页面动效** —— 两件事不要混。脚本没跑起来就停在封面帧上，是个能看的状态而不是白屏（和 `motion-ready` 是同一个降级思路）。不自动播时露出一颗手动播放按钮。
  - `play()` 返回 Promise 且可能被浏览器的自动播放策略拒绝，必须 `catch` —— 未处理的 rejection 会污染控制台，让真正的报错更难找。
  - `webm` 的 `<source>` 排在 `mp4` 前面：浏览器按顺序挑第一个能播的，同画质 VP9 小三成。
  - **登记表是权威**：图片槽即使数据库里塞了视频文件也不会渲染 `<video>`。哪个位置放什么由代码决定，不由数据库里恰好有什么决定。
  - 表单按 `kind` 分流：图片槽根本看不到视频输入框（留着会让站务以为随便哪里都能放视频，而那些位置的模板不渲染 `<video>`，传上去毫无反应）。校验扩展名（值直接进 `<source type>`，传个 `.mov` 浏览器只会静默不播）；体积超 1.5MB 给提醒、超 6MB 直接拒（生产 2 核 1.6G、nginx 直出、无 CDN）。
  - 新增 `fallback_url` 参数给运行时兜底。取用优先级：**数据库片段 → 数据库封面 → 登记表静态兜底 → 运行时兜底 → 空焊盘**。静态那份是仓库里钉死的自有素材，运行时那份是碰运气拿到的（B 站限流就没了）。
  - 落地位置：首页影像区的 B 站 facade 封面（`home.movie.teaser`）。原来只有「B 站封面」和「一块渐变」两种，接口被风控拦下时（412，实测常有）就只剩渐变、什么信息都没有；现在最差也是一个写明要剪什么片子的占位框。B 站长片继续走 facade —— 片段在那里是装饰，facade 自己那颗大按钮才是入口，所以槽位内部的小播放按钮在 facade 里用 CSS 藏掉，占位框也只当背板（两组居中文字叠在一个盒子里会压成一团，截图确认过完全读不了）。
  **踩到的坑**：① 判断「这次请求有没有带新文件」用了 `getattr(f, "_committed", True)` —— `_committed` 是 `FieldFile` 的属性，新上传的 `UploadedFile` 根本没有它，默认值 `True` 让**每一个新上传**都被当成「没变」而跳过校验（三条测试同时红）。改成 `isinstance(f, UploadedFile)`。② 检查脚本里又踩了一次 Lenis：原生 `scrollIntoView` 和它的 rAF 循环打架，目标根本没进视口，于是 IntersectionObserver 永不触发、`play` 调用 0 次。必须走 `lenis.scrollTo(y, { immediate: true })`。③ 两处断言在数「全页的 `.slot`」，影像区一加槽位就把计数和高度集合算进去 —— 断言要说清自己在测哪一块。
  验证：`scripts/check_video_slots.py` 17 条契约。**不测真实解码**：headless Chromium 通常不带 H.264、本机也没有 ffmpeg 现造 WebM，真实播放在这环境里本就不可靠；而需要守住的是**决策逻辑**，所以给 `HTMLMediaElement.prototype.play` 埋点直接观察 video-slots.js 的判断。新增 `VideoSlotRenderTests` 11 例 + `MediaSlotVideoFormTests` 9 例，229 个测试全绿。
