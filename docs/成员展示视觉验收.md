# 成员展示页视觉与交互验收

## 范围

以 `5ddb84a` 为开发基线。仅调整成员墙、共享卡片、独立展示编辑器及展示管理入口；不变更会员资格、授权流程、论坛、任职记录或运行依赖。

## 视觉基准

- 对照 985 × 1597 定稿，用真实 HTML、共享卡片组件与六人虚构样例验收。
- 桌面三列 3:5；平板两列 3:4；手机单列 3:4。同一断点卡片等高，长内容截断，不出现内部滚动条。
- 照片卡保留完整工作场景及底部渐变，文字档案采用米白青灰与衬线标题，工程铭牌使用深色背景和克制刻线。
- 窄屏长昵称的文字遮罩随内容区域延伸；昵称、届别、方向和官方职位不被介绍挤出卡片。
- 1440、985、768、390、320px 检查横向溢出、长昵称、三模块、缺图与键盘焦点。基准样例的页高约 1600px，保留备案链接。

## 功能回归

- 浏览器验证搜索、方向筛选、届别升降序、返回恢复、图片上传、模板切换、背景选择、缩放键盘操作、三模块排序、手机预览与草稿保存。
- `python manage.py test --noinput` 运行完整 Django 测试；SQLite 跳过的两项并发测试须在隔离 PostgreSQL 测试库补跑。
- `python manage.py check_static_pipeline` 检查静态引用、收集及带哈希资源。
- `node scripts/showcase_wall_smoke.js` 检查筛选竞态、中文输入法、浏览器历史、失败降级、图片重新初始化及减少动效清理。
- `node scripts/motion_smoke.js` 保留全站原有动效回归。
- 展示专项测试覆盖旧版快照兼容、背景归属、草稿隔离、撤回/下架、图片引用失效和敏感字段不公开。

## 发布与回退约束

- DEBUG 示例人物和照片只用于本地验收，不在生产数据库创建账号或公开记录。
- 先保留支持 v1/v2 数据的兼容镜像，再发布新版界面。回退只更换代码和静态资源，不恢复数据库备份，不复活已撤回内容。
- 发布前验证数据库备份可恢复、会员和任职数据指纹不变；上线只重建主站应用，不重启论坛或数据库。
- 发布后核验 HTTPS、页面与图片禁止缓存、未授权编辑器跳转、受保护媒体路径、静态资源及定时备份状态。
