# 成员展示与个性化名片

## 成员怎样使用

- 入口：个人中心 → **设计我的展示**，或 `/accounts/showcase/`。
- 已激活的科协会员及以上均可使用，不要求职位。招新成员和预备会员暂未开放。
- 选择工程铭牌、作品橱窗或文字档案；卡片与个人页分别设计，内容不会因换模板丢失。
- 成员墙只呈现最终展示，不提供编辑控件。后台下架入口在管理驾驶舱的“成员展示管理”。
- 卡片可使用自己的工作照、设计师渐变或纯色；照片支持焦点、1–1.5 倍裁切、三级模糊和安全遮罩。卡片背景与个人页封面、账号头像独立。
- 草稿保存后只有本人可见。预览并确认互联网公开说明后发布，才会更新 `/team/` 成员墙与随机地址的个人页。
- 现任职位、任期、可选的任职经历与勋章来自官方记录。任命或卸任不替成员决定是否展示。
- 可随时撤回；修改中的草稿不影响现有公开版本。遇到版本冲突请保留当前内容，刷新后对照，系统不会静默覆盖另一标签页的保存。

## 内容边界

卡片在 960px 及以上采用三列 3:5；640–959px 为两列 3:4，手机为单列 3:4。同一断点内等高，无内部滚动。昵称最多 30 字，短介绍 60 字，标签 4 个，每个 12 字；卡片最多三个可选模块。个人页提供七种模块，结构上限八个，作品与图集各六项。长内容会截断，不挤压身份区。换行分段保留，原始 HTML 不执行。

素材库独立于账号头像。复制头像需要本人操作；图片仅接受真实静态 JPEG、PNG、WebP，5MB / 800 万像素以内，每人最多 20 张。保存经过重新编码的 1600px / 640px 版本，移除 EXIF，不保留原文件。删除素材前，先移除草稿与已发布版本中的引用。

外部链接仅接受 HTTPS；服务器不抓取外站内容、图片或跟踪像素。站内作品必须已公开；后来转为私密的项目关联会立即隐藏。

## 隐私与下架

公开昵称独立于档案姓名。联系方式、学号、生日与性别不会自动进入公开模板或搜索。用户主动填写的昵称、图片、文字和链接仍面向整个互联网，不收录承诺不能当作保密承诺。

站务从管理驾驶舱进入**成员展示管理**，可注明原因下架或解除限制，不可读取私有草稿、私有素材或代为发布。解除限制后须本人重新发布；账号停用或降到科协会员以下同样需要恢复资格后重新发布。等级与任职授权机制未改变。

图片只通过 `/showcase/assets/<uuid>/<small|large>/` 提供。草稿素材仅本人可读；公开素材必须正被有效公开快照引用。页面、图片和错误响应均为 `private, no-store`，个人页附 `noindex, nofollow, noarchive`。撤回阻止新的访问，不保证收回已下载或截取的副本。

## 发布顺序与回退

1. 备份主站数据库、论坛数据、配置与上传目录，保留应用镜像和源代码。
2. **先部署 Nginx 素材保护规则**：`/media/showcase/` 拒绝直链，`/protected/showcase/` 仅内部访问并禁止缓存，再检查 Nginx 配置。
3. 使用当前生产镜像作基础，只复制应用代码，比较前后依赖清单。不借本次功能升级依赖。
4. 在数据库恢复副本上演练 `accounts.0010` 与 `showcase.0001/0002`；比对会员等级、激活状态、站务标志、组与任职记录不变。
5. 短暂停主站，执行迁移并启动新应用；论坛不重建、不重启。验证静态文件哈希、公开与私有接口的缓存及权限。
6. CDN 不得用强制缓存规则覆盖源站 `no-store`。上线后核对成员墙内容；若仍命中旧缓存，刷新 `/team/`，并将 `/accounts/showcase/*`、`/showcase/*`、`/team/*` 设为不缓存。

迁移只接续旧版本已同意且实际公开、仍符合资格的成员，复制既有简介和头像，不添加作品、联系方式或任职经历。损坏或超限旧头像不迁移，文字仍保留。旧开关 `show_on_team` 退役，统一清零，公开同意保存在展示快照中。

回退应用时**保留新表与素材保护规则**，不要逆向恢复旧开关。旧版可能暂时显示空成员墙，这是有意的隐私保护，避免重新暴露已撤回或修改昵称的成员。数据库备份只用于灾难恢复，不作为普通应用回退步骤。

## 验证与维护

设计版本 2 为卡片增加背景配置；读取版本 1 时仅在内存中适配，不批量改写草稿、快照或公开同意。旧橱窗封面接续为背景，保存新版时才写入版本 2。回退必须使用支持两个版本的兼容镜像，不直接回退到不认识新结构的旧编辑器，也不要恢复旧数据库覆盖成员撤回操作。

成员搜索保留 `q/cohort/direction/position/page`，排序为 `sort=cohort_desc|cohort_asc`。`X-Showcase-Partial: 1` 返回同一权限规则下的结果片段，响应包含 Vary 且禁止缓存。筛选支持浏览器前进后退；无脚本时按查找按钮提交普通 GET 表单。

独立样例 `/team/design-demo/` 和其中的照片、个人页仅在 DEBUG 下挂载，不依赖生产会员记录。`?stress=1` 提供长昵称、长内容及缺图场景。照片为 AI 虚构素材，提示词与用途见 `app/showcase/demo_assets/README.md`，不可批量导入线上成员库。部署产物可排除该图片目录。

```bash
cd app
python manage.py test
python manage.py makemigrations --check --dry-run
python manage.py check_static_pipeline
```

`showcase.tests` 覆盖发布、撤回、越权、并发版本、下架、降级、图片与私有字段泄漏。预览和公开页共用 `showcase/card.html`、`showcase/page.html` 与 `showcase.css`。

本地 DEBUG + SQLite 环境可用 `python manage.py seed_showcase_demo` 创建虚构样本，生产配置会拒绝执行。验收包括三套模板、无头像、长昵称、普通/现任/历任成员、320/390/768/1440px 布局、键盘排序与手机预览。样本不是协会真实成员，严禁用于生产数据导入。

所有资格变更须使用既有会员管理或 Django ORM；直接改库绕过业务逻辑不属于支持的操作。私有素材与数据库需要一起备份；日志不记录设计正文或图片内容。
