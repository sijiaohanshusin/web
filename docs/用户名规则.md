# 用户名规则

候选版本规则（尚未上线）：新会员与老会员注册使用同一规则。

- 长度为 2 至 20 个字符。
- 允许常用中文、英文字母、数字、下划线、英文句点、连字符和加号。
- 至少包含一个汉字、字母或数字，不能全部是符号。
- 不接受空格、表情、不可见控制字符、`@`、斜杠及其他未列出的符号。
- 沿用 Django 的 NFKC 规范化及重复用户名校验；例如全角 `Ｃ＋＋新手` 规范化为 `C++新手`。
- 不修改已有账号、会员等级、任职、论坛身份或展示昵称；登录和 SSO 仍以既有用户 ID 关联。

用户名不是自由排版文本。若未来需要空格、表情或更多符号，应先设计主站登录名与论坛名称之间的稳定映射，而不是仅删除前端提示。

论坛兼容性参考当前镜像锁定的 NodeBB 4.14.0：
[用户名及 slug 校验](https://github.com/NodeBB/NodeBB/blob/v4.14.0/public/src/utils.common.js#L331)、
[建号流程](https://github.com/NodeBB/NodeBB/blob/v4.14.0/src/user/create.js)。
本轮验证了主站注册、登录和签名载荷，不把载荷测试称为真实论坛端到端验收。

## 回归验证

在 `app/` 目录运行 `python manage.py test accounts.test_usernames accounts.tests --noinput`。
从仓库根目录运行 `python scripts/check_register.py`，在本地隔离账号上以中文、句点和加号组合用户名完成真实浏览器注册。

覆盖双通道规则、最短/最长边界、纯符号和不可见字符拒绝、全角规范化、大小写重复、登录、成员搜索以及 SSO 资格不变。
