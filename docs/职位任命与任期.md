# 职位任命与任期

## 任命成员

管理员在「管理驾驶舱 → 职位管理」选择职位、任职届次和记录类型。
输入姓名、用户名或学号即可查询候选；可同时按入学届别、学院、当前职位筛选。
同名成员通过用户名与学号区分，选中候选后自动填入唯一用户名。
候选查询仅允许管理员访问，不返回邮箱、电话或生日。
搜索不可用时仍可直接填写完整用户名、学号、唯一姓名或 `#内部编号`。

## 现任与历任

- 任职届次表示任期，例如「2025-2026 届」，与入学年份无关。
- 「现任任命」更新当前职位。换职位或换届时，上一条任职记录自动归档。
- 「历任补录」只添加经历，不替换现任职位，也不授予管理权限。
- 「卸任」保留历史，仅移除职位带来的权限；会员等级及单独授予的管理员权限不变。
- 为已卸任成员补录历史时，必须选择届次；重复提交同一经历不会重复补录。
- 已有任命迁移后显示「届次待补充」，不会猜测任期。为同一现任职位补上届次时更新原记录。
- 自定义职位删除后，历史仍保留当时的职位名称。
- 论坛继续使用现任职位进行 SSO 组同步，历任记录不加入权限组。论坛现有会话仍遵循原有的同步刷新机制。

## 公开展示

成员在「个人中心 → 编辑资料 → 公开团队页」自行勾选并保存。
有职位的成员也可从个人中心的「团队展示设置」直接进入。
未任命时页面说明原因，不提供无效开关。系统管理员身份本身不等于协会职位。
公开团队页仅显示同意公开的现任成员；历任经历由管理员和成员本人查看。
