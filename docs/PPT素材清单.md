# 招新 PPT 素材清单（127 张内嵌图逐张过一遍）

`2025科协招新.pptx`（25 页 / **127 张**内嵌图，27MB，不入库）。这份文档是「哪张图
用了、哪张没用、为什么」的唯一记录 —— 上一轮只挖到 13 张证书就停了，剩下二十多张
没进清单也没写理由，于是等于不存在。

## 怎么重新取

```
python scripts/dump_pptx.py          # 解包到 .artsrc/ppt-dump/ 并打印清单
python scripts/dump_pptx.py --list   # 只看清单，不写文件
```

**这个脚本比「解压出图」多做一件事：把每张图挂到它所在的页码上**，同时导出每页正文。
一张证书照片单看往往认不出是哪一年哪个赛事的哪一条 —— 但同页的正文写着。上一轮
漏掉二十多张就是因为没有这一层关联，看着一堆证书不知道怎么归类。

## 收录判据

1. **姓名必须读得准。** 公开页面上写错一个人的名字，比少一条记录糟得多。
   实测分界线：**长边 ≥590 的读得清，306~309 宽的读不准** —— slide 20 那批
   306 宽的一律不收（`image104/106/107/108/109/110`）。
2. **一本证书拍成两张的，合成一条记录。** 封面页（只有赛事名）不单独成条：
   `image54`↔`image55`、`image61`↔`image60`、`image52`↔`image53` 都是同一本。
3. **同一条的重复拍摄取更清楚的那张**：`image70` = `image56`（北斗杯），
   `image88` 比 `image77` 更清楚（2024 TI 杯国二，**换成 image88**）。
4. **多张摊开的合照只录读得出的那一张。** `image71` 是一叠黑龙江赛区证书扇形摊开，
   只有最上面那张的姓名可读，其余被压住 —— 录一条，不猜其余。
5. **奖杯奖牌合照不是证书。** `image69` 是四座奖杯/奖牌摆在一起，没有任何一条
   记录能对应它。

## 口径：姓名一律部分脱敏（已定）

**保留首尾、中间打星** ——「李小明」→「李*明」，两个字的只留姓（「张伟」→「张*」），
罗马字名保留姓、名按同一规则（「Li Xiaoming」→「Li X******g」）。
规则与工具在 `scripts/mask_names.py`（带 `--self-test`）。
**这里的示例是虚构名** —— 拿真人当脱敏规则的示例本身就是泄漏。

这个口径覆盖**全部**记录，不分届别 —— 上一轮那 15 条（当时按「已征得同意公开」
录了真名、并且已经上线）也一并改了。理由是分届别要解释一条时间线，而
「协会 2011 年拿过全国二等奖」这个事实本来就不依赖于把三个人的名字挂在公网上。

三条配套的硬性做法：

1. **真名只存在 `.artsrc/honors-names.txt`（不入库）。** 这个仓库是**公开的**，
   `ops/deploy.sh` 也是靠公开 tarball 拉代码 —— 真名一旦写进 `import_honors.py`
   就等于发布了。渲染时脱敏只能挡住网页那一层，挡不住 git。
2. **`python scripts/mask_names.py --scan` 拿底稿扫整个仓库。** 真名不只会出现在
   数据文件里 —— 文档、注释、测试用例都行，逐个手改必然漏一个，而漏掉的那一个
   不会以任何形式报错。加 `--redact` 就地替换。
   （这个扫描第一次跑就抓出一处我不知道的：`docs/2026改版计划.md` 里写着
   「群主 <学号><姓名> 的修改意见」—— **姓名带学号**，比单独的姓名更糟，
   已整段删掉。）
3. **`news/tests.py` 有一条独立断言**扫 `HONORS` 的每个 `awardee`，漏一个就红。
   它刻意不 import `mask_names.py`、自己重写判据 —— 拿同一个函数验它自己的输出，
   等于什么都没验。

**指导教师不脱敏。** 竞赛证书上的指导教师是职务署名，学院公众号发获奖通报时也是
指名写的（`image45` 就是一例）。这是一处判断，不是漏做。

**证书图片同样要遮。** 老证书上印着姓名，图一贴上去等于没脱敏 ——
`scripts/build_certs.py` 里逐张标了姓名区域，处理方式与验收见那个脚本。
