# HEU ESTA 官网维护手册

本文档面向每一届网站维护成员，只记录协会网站及其生产部署。账号密码、SSH 私钥、邮箱应用专用密码和环境文件内容不得写入仓库。

## 1. 线上架构

```text
访问者
  └─ CDN / HTTPS
      └─ Nginx
          ├─ Django + Gunicorn：官网、会员、招新和驾驶舱
          ├─ PostgreSQL：主站与 NodeBB 独立数据库
          ├─ NodeBB：会员论坛与公共邮箱归档
          ├─ /static/：版本化静态文件
          └─ /media/：受控上传文件
```

| 位置 | 用途 |
| --- | --- |
| `/opt/heuesta/web` | 部署代码与脚本 |
| `/opt/heuesta/.env` | 主站生产环境变量，不进入 Git |
| `/opt/heuesta/forum.env` | 论坛和 IMAP 环境变量，不进入 Git |
| `/srv/heuesta/static` | Django `collectstatic` 输出 |
| `/srv/heuesta/media` | 用户上传内容 |
| `/srv/heuesta/backups` | 自动与手动备份 |
| `/etc/nginx/sites-available/` | 主站和论坛 Nginx 配置 |

## 2. 会员与权限

`accounts.User.member_level` 是等级的单一事实来源：

| 等级 | 名称 | 主要权限 |
| --- | --- | --- |
| 0 | 待审核 | 老会员身份核验中，账号未激活 |
| 1 | 招新成员 | 登录、公开公告、招新申请、个人资料 |
| 2 | 预备会员 | 会员资源、活动报名、项目列表、论坛 SSO |
| 3 | 科协会员 | 科协会员私密论坛版块 |
| 4 | 站务管理 | 管理驾驶舱与内容维护 |
| 5 | 系统管理员 | 站点设置与高级后台 |

招新成员的内容权限与游客相同，只能看到 `min_level=0` 的公开内容。旧“报名会员可见”内容在迁移时统一提升为“预备会员及以上”。

固定职位：主席、硬件主席、软件主席、硬件副主席、软件副主席。主席和两类主席的 `grants_management` 为真，可进入管理驾驶舱；副主席不会因职位自动获得站务权限。高级后台仍要求系统管理员或工作人员状态。

## 3. 正式招新

### 3.1 新会员通道

入口：`/accounts/register/new/`。

新会员完成固定学院、届别、擅长方向和邮箱验证后自动激活为招新成员，并跳转 `/recruitment/`。他们可以立即提交一次招新申请，但不能访问资料站会员内容、活动报名、项目、驾驶舱或论坛账号。

### 3.2 老会员通道

入口：`/accounts/register/returning/`。

老会员申报原届别和固定协会身份后，账号保持未激活。驾驶舱“会员管理 → 老会员审核”显示完整资料；审核时可修正职位并批准或拒绝。拒绝只改变状态，不删除账号或审核记录，之后仍可重新审核。批准后账号成为科协会员并发送邮件通知。

### 3.3 面试流程

- 招新成员提交报名后等级不变。
- 一面通过：申请状态更新并晋升预备会员。
- 二面通过：申请状态更新并晋升科协会员。
- 未录取：只更新申请状态并通知本人，不自动删除账号。
- 同一用户在同一批次只能提交一次申请。

“2026 秋季招新”由迁移幂等创建并立即开放，截止时间为空。招新 QQ 群为 `1081376858`。

## 4. 日常管理

管理驾驶舱：`https://heuesta.cn/dashboard/`。

- 会员管理：老会员审核、招新成员筛选、等级调整和积分调整。
- 招新管理：批次、报名名单、面试结果、备注与 CSV 导出。
- 公告与活动：发布 Markdown 内容并选择公开或会员可见等级。
- 资料与项目：上传、授权、归档和成员管理。
- 网站问题反馈：查看、回复和关闭反馈；历史内测反馈已保留。
- 职位管理：仅可任命或解除五类固定职位。
- 站点设置：系统管理员维护公开配置；旧内测与自动审核开关已停用且不再显示。

高级后台 `/admin/` 只用于底层数据核对和系统管理员操作，日常维护优先使用驾驶舱。

## 5. 发布与备份

发布前先确认工作区、迁移和测试：

```bash
cd app
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

推送 `main` 后，在服务器执行：

```bash
sudo /opt/heuesta/web/ops/backup.sh
sudo /opt/heuesta/web/ops/deploy.sh
sudo /opt/heuesta/web/ops/forum/deploy-forum.sh
```

论坛部署脚本会同步正式用户组、隐藏旧组、更新私密版块权限、激活公共邮箱插件、应用主题，并把旧内测公告和反馈帖取消置顶后锁定归档。

备份应至少包含主站 PostgreSQL、NodeBB 数据库、主站媒体、论坛上传文件和论坛配置。恢复属于高风险操作，必须先验证备份文件并安排维护窗口。

## 6. CDN 与缓存

- `/accounts/register/`、两个注册通道和 `/recruitment/` 发送禁止缓存响应。
- 二维码等静态资源使用内容哈希文件名，可长期缓存。
- 正式发布后在腾讯云 CDN 控制台刷新首页、招新页和注册页 URL。
- 页面未更新时先检查源站，再检查 CDN 命中和浏览器缓存。

建议刷新：

```text
https://heuesta.cn/
https://heuesta.cn/recruitment/
https://heuesta.cn/accounts/register/
https://heuesta.cn/accounts/register/new/
https://heuesta.cn/accounts/register/returning/
```

## 7. 论坛

预备会员及以上才会获得论坛 SSO Cookie。论坛本地注册保持关闭，身份和组由主站 JWT 与 Session Sharing 同步。

正式等级组：招新成员、预备会员、科协会员、站务管理、系统管理员。招新成员实际不会获得论坛登录。旧“报名会员、正式会员、干事、管理员”组隐藏保留一个迁移周期，并在成员重新登录时从同步白名单中移除旧身份。

“内部事务”和“公共邮箱”等私密版块需要显式撤销游客、普通注册用户、招新成员和预备会员权限，再授予科协会员及以上组。不要只依赖前端隐藏。

### 公共邮箱

`nodebb-plugin-heuesta-mailbox` 通过 Gmail IMAP 只读归档 `heuesta@gmail.com` 上线后收到的新邮件：

- 每个发件人一个主题，同一发件人的后续邮件按时间追加楼层。
- HTML 经白名单清理后在沙箱预览，纯文本作为后备；远程图片、脚本和表单被移除。
- 附件只记录名称、MIME 类型和大小，不下载正文。
- 科协会员及以上只读，机器人负责发帖，NodeBB 管理员可以删除归档。
- 首次连接只建立基线，不导入历史邮件。

应用专用密码只保存在 `/opt/heuesta/forum.env`，文件权限保持 `600`。密码泄露时立即在 Google 账号撤销并重新生成，然后重新部署论坛。

## 8. 验收与故障排查

| 症状 | 优先检查 |
| --- | --- |
| 主站 502 | 应用容器状态、应用日志、数据库健康状态 |
| 论坛 502/504 | NodeBB 容器日志、4567 本地监听、内存与构建状态 |
| 页面不是最新版 | 源站响应、CDN 缓存刷新、静态文件哈希 |
| 注册失败 | 验证码日志、邮箱发送、频率限制、唯一性错误 |
| 老会员不能登录 | 审核状态与 `is_active`，不要手工跳过审核记录 |
| 招新成员看到会员内容 | `content_level()`、内容 `min_level`、模板导航与接口权限 |
| 招新成员登录论坛 | SSO Cookie 清理、主站等级、Session Sharing 配置 |
| 私密版块泄露 | NodeBB 服务端版块 ACL，不要只看导航是否隐藏 |
| 公共邮箱不更新 | ACP 同步状态、IMAP 环境变量、Google 应用专用密码状态 |

发布验收必须覆盖桌面与手机注册页、两个注册通道、招新申请、面试晋级、论坛 SSO、私密版块、HTTPS、Nginx、容器和定时备份。

## 9. 安全约定

- 不提交 `.env`、密码、验证码、OAuth/IMAP 凭据、SSH 私钥或数据库备份。
- 不在日志或工单粘贴邮件正文、应用专用密码或完整身份资料。
- 不恢复旧内测自动提权命令，不通过配置把普通注册者提升为站务管理。
- 修改权限时同时检查页面、视图/API、数据库约束和 NodeBB ACL。
- 涉及迁移、论坛插件或 Nginx 的变更，必须先备份再发布。
