# 成果体系候选版验收

日期：2026-09-06。状态：实现与隔离验证已完成，整理为可推送候选版本，尚未部署。提交与远端 CI 结果见后续交付记录。没有修改正式会员、正式奖项或原主工作区。

## 体系与边界

- 一条 Project 作品可关联多条 Honor 奖项。两者继续作为各自公开墙的数据源，不另造一份统计台账。
- Contributor 将公开署名、分工、可选届别与账号关联分开；未注册者可以先保留署名，注册后再认领。不会按同名自动绑定或拆解历史获奖人字符串。
- 指定已注册用户名后由本人确认；姓名重合、名单缺失等认领由站务核验。站务不能批准自己的申请。
- 成员创建、预览、发布、更新和撤回自己的荣誉；旧协会记录保持原维护方式，不自动转给新注册账号。
- 参与关联不授予作品编辑、项目档案、会员等级、职位或论坛权限。公开模板只读取显式填写的署名，不公开关联账号的档案姓名、邮箱、学号和联系方式。
- 同年度、名称、团队署名相同的作品阻止重复发布；奖项另外比较赛事和级别。近似名称、缩写、不同署名或历史重复记录仍需人工核验，不承诺语义去重，不自动合并或删除。
- 荣誉按年份降序，再按重要性、奖项级别和稳定字段排序。站务可排序与精选，不通过旧荣誉管理入口改写成员发布内容。
- 已关联成员或存在认领的成果撤回后保留档案，不能由作者直接删除关联历史。
