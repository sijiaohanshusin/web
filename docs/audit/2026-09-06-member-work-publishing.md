# 成员自主作品发布验收

核验日期：2026-09-06。状态：本地候选版，未部署正式站，未修改正式数据。本轮使用隔离数据库、素材目录和虚构账号完成写入验证，不改变论坛、任职记录或会员等级。

## 规则与入口

- 已激活的科协会员及以上可从个人中心进入 `/works/mine/`，无需任职或站务批准。
- 作者自行填写图文和公开署名，保存草稿、预览、同意公开、更新或撤回。账号档案姓名和联系方式不自动进入作品。
- 私有草稿与已发布快照分离。修改并保存草稿不替换当前公开内容，发布要求最新版本和有效预览凭证。
- 站务从 `/works/manage/` 搜索公开作品，只调整重要性与首页精选，不能读取他人草稿、编辑成员作品或代替作者发布。
- 默认按作品年份降序、重要性降序排列；同年同重要性时精选靠前，再按作品编号降序稳定排列。修改内容不提升排序。
- 个人展示页中的作品模块与协会作品墙是两个入口，不自动互相发布，不授予项目成员身份或档案权限。原项目及整数作品地址继续兼容。

## 数据与图片保护

迁移 `projects.0003_member_work_publishing` 新增作品草稿、发布快照和受保护图片，并为既有项目补充年份及重要性。历史年份取原创建时间的本地年份，不自动公开旧内容。

上传复用现有静态 JPEG、PNG、WebP 检查、5MB 和 8MP 上限、重新编码及 EXIF 清除。图片只能经鉴权接口读取，原始上传目录仍拒绝访问。草稿图片仅本人可读；其他访问者只能读取有效公开快照中引用的图片。撤回、停用或降级后拒绝新的公开页面和图片请求；恢复资格不自动重新公开。

删除图片同时检查已保存草稿和公开版本引用。新建、保存、发布、撤回与删除采用一致的账号和作品锁顺序。版本冲突返回 409 并保留表单输入，不静默覆盖。
