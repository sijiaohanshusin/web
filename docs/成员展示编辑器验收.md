# 成员展示编辑器：首轮验收

日期：2026-09-03 至 2026-09-04。基线：`8998e97`。开发分支：`codex/showcase-editor-20260903`。

本轮先在隔离环境交付可交互版本，须负责人体验确认后才能安排上线。原工作区的其他修改未带入，论坛、会员等级及真实任职记录未调整。

## 体验入口

- 编辑器：`/accounts/showcase/`，使用具有展示资格的已激活会员账号。
- 分区可通过 `?section=card-layout`、`card-background`、`card-content`、`page-layout`、`page-works`、`page-gallery`、`assets`、`publish` 定位。
- 个人中心与编辑资料页均保留展示状态和编辑入口；`/team/` 仍是纯浏览页面。
- 本地验收账号由 `python manage.py seed_showcase_editor` 创建。命令只允许 DEBUG + SQLite，重复执行不会覆盖草稿，也不自动发布。不得在正式环境使用。
- 本地启动方式：在 `app` 目录使用已有项目 Python 环境执行 `python manage.py migrate`、`python manage.py seed_showcase_editor`、`python manage.py runserver 127.0.0.1:57806 --noreload`。仅监听本机，不接入生产数据库。

## 本轮实现

- 三套卡片与三套独立个人页模板；“工程铭牌”采用器件档案、工作台封面和仪表信息构图，“文字档案”采用纸张、声明与出版信息构图，“作品橱窗”保持既有照片导向布局。模板缩略图、双预览、成员墙和详情页复用服务端组件。
- 照片、渐变、纯色背景；焦点、缩放、模糊、安全遮罩及独立封面，保留隐藏内容。
- 内容排序、官方记录自主展示、最多六件作品、稳定的卡片精选作品选择、图集和 HTTPS 链接。
- 共用受保护素材库，显示处理后的实际格式、尺寸、体积和引用用途；删除前复查草稿与公开引用。
- 保存状态与公开状态独立；显式保存、双预览、同意公开、发布、撤回；失败保留输入，多标签版本冲突不覆盖。
- 服务端字段校验可定位分区，手机独立预览面板、键盘排序、照片方向键调整、无脚本提示与减少动效兼容。

## 推荐验收顺序

1. 切换三套卡片模板，确认昵称、图片和介绍不会丢失。
2. 更换背景照片，调整焦点、缩放和遮罩；切换渐变后再切回照片。
3. 关闭、开启并移动内容模块，检查卡片桌面与手机版。
4. 选择个人页模板、作品、图集和链接；调换作品顺序，确认卡片精选作品不随之改变。
5. 在素材库检查用途；移除引用后先保存，再删除未被公开版本引用的图片。
6. 保存后检查双预览，自行同意并发布；打开成员墙与个人页核对结果。
7. 修改草稿但不发布，核对原公开版本不变；再撤回，核对页面和图片停止新访问。
8. 同时打开两个编辑页，先后保存不同修改，检查冲突提示与版本对照。

## 数据与上线约束

设计结构为 v3。v1/v2 在读取时兼容升级，旧作品标识确定性生成；读取、预览不改写数据库快照，保存或发布才写入 v3。背景、作品、图集仍走原有素材归属与公开引用校验。

新增迁移仅补充素材安全名称和处理后体积，不迁移授权、不自动公开。旧素材显示中性名称。关联项目仍只允许公开项目，不授予项目成员身份或编辑权限。

正式发布顺序固定为：负责人确认后备份数据与配置、部署兼容版本及静态资源，再验证保护图片接口和生产缓存策略。只更新主站，不重启论坛。

回退版本必须能读取并保留 v3 数据；不可直接切回只会写 v1/v2 的旧编辑器。回退不恢复旧数据库，不覆盖成员新草稿，不重新公开已撤回或被下架的内容。正式站缓存、HTTPS 和 Nginx 验收留到批准上线后执行。
